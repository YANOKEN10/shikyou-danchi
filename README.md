# 死鏡団地

四号棟・解体前夜。取り壊し直前の団地に、母のノートを取りに戻る一人称ホラー。
ブラウザだけで遊べます。インストールもプラグインも要りません。

**公開URL**（デプロイ後）: <https://shikyou-danchi.vercel.app>

- 画像ファイル・音声ファイルは 1 つも使っていません。
  形も、汚れも、効果音も、すべてその場で作っています（Three.js ＋ WebAudio）。
- ビルド不要。`index.html` を開けばそのまま動きます。
- パソコンでもスマートフォンでも、**同じアカウントで続きから**遊べます。

---

## ログインのしくみ

| | |
|---|---|
| **メールアドレスなしで登録できる** | 名前 ＋ 合言葉 だけ。子どもや、メールを持っていない人でも遊べます |
| **メールアドレスでもログインできる** | あとから登録すると、名前でもメールでもログインできるようになります |
| **ログインしなくても遊べる** | 「この端末だけ」を選ぶと、その機械の中だけに記録が残ります |
| **あとからログインしてもよい** | ゲーム中にログインすると、そのときの進み具合をそのままクラウドに預けます |
| **どの端末でも続けられる** | 記録はサーバーに1人1ファイル。PC で 3 階まで進めて、続きをスマホで遊べます |

Claude を経由しません。公開URLを開けば、そこがそのままゲームです。

### 安全のためにしていること

| | |
|---|---|
| 合言葉 | そのまま保存しません。利用者ごとの乱数を混ぜて `scrypt` でハッシュ化 |
| 照合 | 時間差から中身が漏れない比べ方（`timingSafeEqual`） |
| 間違えたとき | わざと少し待たせて、総当たりを遅くする |
| ログイン状態 | HMAC-SHA256 で署名した券。1年で切れる。合言葉は端末に残しません |
| 記録 | 非公開の Blob に、利用者1人＝1ファイル。ファイル名も推測できないハッシュ |
| 呼び出せる場所 | 公開URLと localhost だけに限定（CORS） |
| 記録の大きさ | 1人 300KB まで |
| 二重に進めたとき | 版（rev）を見て、古い記録での上書きを止め、どちらを残すか尋ねます |

**合言葉を忘れると、メールアドレスを登録していない場合は取り出せません。**
心配な方は、ゲーム内の「小休止 → アカウントの設定」からメールアドレスを登録してください。

## 遊びかた

五階建ての外廊下を、階段で一階ずつ上がります。各階に一つだけ、入れる部屋があります。

| パソコン | |
|---|---|
| W A S D | 移動 |
| マウス | 見まわす（画面を1回クリックで視点が固定されます） |
| Shift | 走る（足音が響き、まず見つかります） |
| Ctrl / C | しゃがむ（静かに歩く） |
| E / 左クリック | 調べる・開ける |
| F | 懐中電灯 |
| Tab | 手帳（持ち物とメモ） |
| Esc | 小休止（記録・設定・ログイン） |

| スマートフォン | |
|---|---|
| 左のつまみ | 移動 |
| 画面をなぞる | 見まわす |
| 調 / 走 / 屈 / 灯 / 帳 / 休 | 上と同じ |

横向きにすると見やすくなります。

### 気をつけること

- **懐中電灯の電池は減ります。** つけっぱなしだと十分ほどでなくなります。予備は部屋の中に落ちています。
- **音を立てると聞きつけられます。** 走る＞歩く＞しゃがむ の順に響きます。
- **住戸の中と階段室は安全です。** 追われたら、開いている扉に飛び込んでください。
- **懐中電灯を正面から当てると一瞬止まります。** ただし何度も効きません。止まったあとは速くなります。
- **四階からは、そのままでは上に行けません。**

### 終わり方

見つけたメモの数で変わります。全部で 7 つあります。

## 手元で動かす

```bash

```

<http://localhost:5180> を開いてください。
記録は `.devdata/` に溜まります（Blob の代わり）。

## 公開するための準備（Vercel 側）

コード（`api/`）は書き終わっています。Vercel 側で保管庫を1つつなぐだけで動きます。

### 1. 記録の保管庫（Blob ストア）をつなぐ

1. <https://vercel.com/dashboard> → プロジェクト **shikyou-danchi** を開く
2. **Storage** → **Create Database** →  **Blob**（既存のストアの **Connect** でも可）
3. **Connect to Project** で `shikyou-danchi` を選び、環境は **すべて** にチェック

これで `BLOB_READ_WRITE_TOKEN` が自動で設定されます。
ボンバーマンや廃校おばけで作ったストアを使い回しても構いません（その場合も Connect は必要です）。
記録のファイル名は `sk/` で始まるので、他のゲームと混ざりません。

### 2. 署名用の合言葉を足す

**Settings** → **Environment Variables** → **Add New**

- Key: `AUTH_SECRET`
- Value: 長いランダムな文字列（40文字以上。人に見せない値）
- Environments: **すべて**

> この値でログインの券に署名します。**あとから変えると、全員がログインし直しになります。**

### 3. 確かめる

<https://shikyou-danchi.vercel.app/api/health> を開くと、こう出れば準備完了です。

```json
{ "ok": true, "store": "blob", "hasBlobToken": true, "hasAuthSecret": true, "configured": true }
```

`configured: false` のあいだは、ログインの代わりに「この端末だけ」で遊べます。

```

serve.js        手元用のサーバー（公開されません）
api/            ログインと記録（Vercel の関数）
  _lib.js         合言葉・券・メールの対応づけ
  _store.js       Blob と .devdata/ の両対応
  auth.js         登録・ログイン・名前の空き確認
  account.js      メール登録／変更、合言葉変更、退会
  save.js         記録の預け入れ・取り出し・版の突き合わせ
  health.js       準備できているかの確認
src/
  main.js         起動、ログイン画面の受け答え
  game.js         進行、階の出し入れ、調べる、保存
  build.js        団地の組み立て（廊下・住戸・階段室）と当たり判定
```
