Vitruvian by Sean Buckley and Olaf Delgado-Friedrichs (relicensed from Antonia Polygon), distributed with CharMorph. Additional credits: SirMaxim (skin LUT), Upliner (original Antonia rigging), Mindfront (eyebrows), J Hill (lacrimal/sclera textures).

human.bin / human.json contain extracted static head and clothed body geometry, UVs and four CC0 facial shape keys. No Mixamo motion clips, animation buffers, skeleton or third-party tool code are included. Arms have been repositioned for the mirror. Texture derivatives are resized WebP versions of vit_face_bc.png, vit_face_n.png, vit_body_bc.png and vit_mouth.png. Horror colors, clothing material settings, eyes and procedural motions are project modifications.

The original downloaded GLBs remain in work/cc0-source for provenance; only the extracted runtime assets in this directory are published.
